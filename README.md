**Project: AI Spam Detector**

This is a machine learning web application that checks whether an SMS or email message is **spam** (unwanted or fraudulent) or **ham** (a normal, legitimate message). The user types or pastes a message into a text box, clicks a button, and the app instantly shows the result.

Behind the scenes, it uses Natural Language Processing (TF-IDF) to turn text into numbers and a Multinomial Naive Bayes classifier to predict the category. The project is built in Python with scikit-learn and has a simple interface made with Streamlit, plus an alternative Flask version.

**Purpose:** To demonstrate a complete machine learning workflow, from creating data and training a model to deploying it in a usable web app.
